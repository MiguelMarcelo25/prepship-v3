## Remaining PS-441 defect closed

The remaining card-specific defect entered when `BillingView` switched preview
rows and passed the previous order's unsaved draft to
`billingEditDraftForRow`. The helper fuzzy-matched package id/name and copied a
positive box cost into another order whose authoritative amount was zero. That
made a frontend cache an alternate money source.

The fix removes that cross-order carry path. A draft is now restored only by an
exact order cache key. The frontend does not infer a reusable box price; the
existing backend PS-311 preview/apply commands remain the only workflow for an
operator to intentionally apply a reviewed box cost across orders. The focused
guard proves same-order restoration and rejects both same-box and different-box
cross-order inheritance.
