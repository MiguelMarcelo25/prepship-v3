## Locked-surface override

`web/src/components/Views/OrdersView.tsx` was changed under the user's explicit `unlock shipped data` override. The change removes frontend test-rate fabrication and fallback persistence so Apply always delegates to the existing backend command and quote proof. It does not weaken `isReadOnly`, shipped/cancelled checkbox gates, batch suppression, Select All suppression, `assertOrderEditable`, or any database lock.

No live label, postage purchase, marketplace notification, production database mutation, or shipped/cancelled SQL update/delete is performed by the PS-433 guard or verification commands.
