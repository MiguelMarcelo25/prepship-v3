# Site Action Functionality Matrix

PS-022 upgrades this file from a loose inventory into a strict action contract. Every critical action below must either be covered by automated mocked/sandbox certification, or explicitly marked manual-gated/blocked with a reason. Automated tests are mocked only by default: no real postage, no live provider calls, no marketplace notifications, no production order mutation, no shipped/cancelled mutation, no real invoice generation, and no secrets/PII/raw labels in fixtures or output.
